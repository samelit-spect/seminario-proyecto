# Plan del Proyecto - Seminario Tecnicatura en Desarrollo de Software

## Proyecto: TechStore - Tienda Online de Electrónica

### Stack Tecnológico
- **Frontend:** React + TypeScript + Vite
- **Estilos:** Tailwind CSS
- **Backend:** Firebase (Auth + Firestore + Storage)
- **Despliegue:** Netlify (SPA en la raíz del repo, `npm run build` → `dist`)

---

## Funcionalidades

### Cliente
- Registro / Inicio de sesión (Google o email)
- Catálogo de productos con filtros (categoría, precio, búsqueda)
- Detalle de producto
- Carrito de compras
- Checkout con formulario de envío
- Historial de pedidos
- Perfil de usuario

### Administrador
- Dashboard con estadísticas (ventas, productos, usuarios)
- CRUD de productos
- Gestión de pedidos (Pendiente → Enviado → Entregado)
- Gestión de usuarios
